DATAFORGE AI — ЗАПУСК НА WINDOWS

1. Распакуй архив в удобную папку.
2. Открой PowerShell в этой папке.
3. Выполни:
   python -m venv .venv
4. Активируй окружение:
   .\.venv\Scripts\Activate.ps1
5. Установи зависимости:
   python -m pip install -r requirements.txt
6. Запусти сайт:
   python app.py
7. Открой в браузере:
   http://127.0.0.1:8000

Для проверки загрузи файл sample_invoice.pdf.

ВАЖНО:
- Сейчас это MVP, а не законченный коммерческий сервис.
- Оплата пока не подключена.
- Сканированные PDF (изображения) пока не обрабатываются через OCR.
- Сервис извлекает таблицы из обычных текстовых PDF и формирует .xlsx.
